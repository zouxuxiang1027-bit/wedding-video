## 替换步骤

### 方法一：从 macOS 照片库导出（推荐）

1. 打开 **照片（Photos）** 应用
2. 找到 11 张婚纱照
3. 全选 → 右键 → **导出** → **导出 11 张照片**
4. 将导出的文件按上表重命名为 `photo-01.jpeg` ~ `photo-11.jpeg`
5. 覆盖到 `public/photos/` 目录

### 方法二：直接拖放覆盖

1. 在 Finder 中打开 `public/photos/` 目录
2. 将真实照片逐一拖入并**替换**对应编号的占位图文件
3. 确保文件名完全一致（包括大小写）

### 方法三：命令行复制

```bash
# 假设你已将照片导出到 ~/Desktop/wedding-photos/
cp ~/Desktop/wedding-photos/额头吻.jpg public/photos/photo-02.jpeg
cp ~/Desktop/wedding-photos/新娘团扇.jpg public/photos/photo-04.jpeg
# ... 以此类推
```

## 照片格式要求

- **格式**：JPEG (.jpeg / .jpg) 或 PNG
- **方向**：竖版（portrait）优先——组件会自动做 16:9 信箱化垫底
- **分辨率**：建议 >= 1080px 宽（高分辨率更好）
- **色彩**：保持原片色调即可，LUT 调色由 Remotion 组件处理

## 替换后验证

```bash
# 启动 Remotion Studio 预览
npx remotion studio

# 浏览器打开 http://localhost:3000 后选择 wedding-opening 合成
# 确认每张照片正确显示在对应分镜中
```

## 注意事项

- 替换后**无需修改任何代码**——文件名映射已在 `src/timeline.ts` 的 `PHOTO_MAP` 中定义好
- 若某张照片暂时没有，占位图不会导致渲染失败，只是显示为纯色块
- 建议所有 11 张全部替换后再执行最终渲染，效果最佳
